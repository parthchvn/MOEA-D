# Preserved historical work

These scripts and the notebook are retained verbatim from base commit
`76df0006c3770106b41dca05914301b97cb2132a`. They are not the active implementation.

**Do not use their theorem-like plot captions or historical runtime estimates
as validated conclusions.** The scripts use different scalarizations, mating
rules, neighborhoods, and stopping/accounting conventions. See
[the migration audit](../docs/migration.md) for the differences and known issues.

New experiments run through `python -m moead.experiments`; their raw data and
provenance are under `evidence/neighborhoods/`.
