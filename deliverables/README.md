independent analytic review. For even n>=4,
`|RORR| <= 1024 (n+1)^3 (20n)^4/q < 4e9 n^8` sweeps, where
`q=1-(1-d(2,0))(1-d(1,0))` and d is standard-bit mutation at rate 1/n.

second concurrent agent. It upgrades one ordered coefficient from candidate

conjectured polynomial in the published project; no uniform remainder,
fixed-positive-c ordering or ordinary-initialization theorem follows.

**Mechanically checked, distinct from proof.** The new solver imports no
earlier solver. It sums one circular pass of phase forcings before the
first clean population change, divides by the clean escape probability,
and recursively uses states with fewer errors. The aligned boundary is
killed separately. Independent custom rewards count orphan turns, integrate
the centered forcing, and retain the outer R insertion.

The declared finite grid uses both corner/aligned origins, every regular
target, every orphan value and every phase. Child weights are all 0,...,n
at n=4 and {0,k,n} at n=6. It is a bounded mathematical check designed this
round, not a preregistered stochastic experiment or exhaustive enumeration
of all populations. Every arithmetic decision uses exact fractions.
Hashes are SHA-256 of Python's exact fraction or tuple string; decimals
are for presentation. There is no sampling uncertainty or censoring of
these completed deterministic calculations. No scientific seeds are used.
The custom exact harness is used because the trajectory-grid runner does
not solve signed phase equations.

**Verified dependency scope.** The receipt/registration audit from round 3
is rerun, reproducing six files byte for byte and checking independent seed
separation. The round-18/19 published artifact manifests and targeted tests
are checked. The marked two-R lemma is rederived in the new proof and
checked by the independent solver. The complete large round-18/19 grids
are not rerun; no such recursive replay is claimed. No earlier plan or
