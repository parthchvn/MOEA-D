# Round 13: the signed cubic supplied-corner coefficient

**Candidate proof: the cubic coefficient is polynomial for both parities.**
The proposed bound is |C_n|<=10^10 n^7, where
E tau_3-E tau_2=p A_n+p^2 B_n+p^3 C_n+O_n(p^4), in sweeps.
The argument retains the two acceptance factors that create a bad pair,
and subtracts the autonomous orphan hitting function before bounding mixed
insertions. Independent review of the new argument remains necessary.
It does not establish a uniform higher-order remainder or enlarge the
full-process noise window. See [the proof and falsifiers](proof.md).

The oracle matches 28 rational quantities across 6,762 population/cardinality
cases. Twenty lower-order quantities reproduce the published round-8 evidence.
There are no sampling confidence intervals, censoring, fitted laws, or new
random seeds in these algebraic checks.

**Mechanically checked cancellation:** at n=32, with the last nonorphan pair
also erroneous, the first O response and the autonomous orphan first response
both round to -2.2726578815737482e57. Their **exact** difference is
6.121388487442983e-44. A separate stopped-occupancy recursion reproduces the
difference. Floating-point subtraction would lose it. [cancellation.csv](cancellation.csv)
retains four witnesses and exact-rational hashes.

The default reproducer runs computations serially with numerical thread
limits set to one. It replays round 11 and its recursive dependencies, then
replays round 12's phase, pair, tensor-row and higher-moment certificates.
The large round-12 positive-p full Schur solve is not a premise of this
cubic argument and is not rerun; its published artifact hash is checked.
All four relevant round-12 tables reproduce byte for byte.

The reproducer then generates the exact cubic grid, independent oracle,
recipient-word and excess checks, and compact artifacts. Its logs and large
fractions remain in the requested replay directory. `--reuse-work PATH`
revalidates and recurates an already completed work directory; that mode
does not constitute a second run of the algebra. The full n=4 oracle was
completed once this round, with exact cross-implementation comparison;
it was not rerun merely to obtain identical bytes. The same distinction
applies to the compact artifact replay recorded in [checks.json](checks.json).
